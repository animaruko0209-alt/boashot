# ボアショット / BOASHOT

敵弾を吸収し、得たエネルギーを攻撃・防御・強化に使う、DxLib製のトップビュー横スクロールシューティング試作版です。Windows / Visual Studio 2022 / C++17向け。

## 遊び方

`x64/Release/boashot.exe` を起動し、Enterで出撃します。道中の最後に現れるボスを倒すとクリアです。クリア画面でEnterを押すと次のステージへ進みます。

| 操作 | キー |
| --- | --- |
| 移動 | WASD / 矢印 |
| 通常ショット | 左クリック。長押しで連射。エネルギー消費なし |
| 吸収 | 右クリックを押している間。前方の扇形に入った敵弾・スキル残骸を即時に回収 |
| アクションを選択 | ホイール上でチャージ → グレネード → バリアの順。下で逆順 |
| チャージ | 選択後、Spaceを長押ししてエネルギーを確保し、離すと貫通ショット |
| グレネード | 選択後、Spaceを押すと発射。着弾時に周囲の敵へダメージ |
| バリア | 選択後、Spaceを押している間、通常の敵弾も吸収できない岩も防ぐ |
| オンパレード | スキル取得後にI。一定時間、吸収範囲が広がり、クールタイムが短くなる |
| 一時停止・再開 | P / Esc（再開はEnterでも可） |
| タイトルへ戻る | 一時停止中にQ。クリア・ゲームオーバー画面ではEsc |

## ゲームの仕組み

- **吸収。** 一定時間続けられ、止まるとクールタイムが始まります。使った時間が長いほど回復が遅くなります。回復後に右ボタンを押し直すと再開します。満タンでも敵弾は取り込めます。岩は移動で避けるかバリアで防ぎます。
- **エネルギー。** 吸収と選択中のアクションは切り替えて使います。チャージを別のアクションや吸収で中断すると、確保した分が戻ります。チャージ量が増えるほど弾の威力と速度が上がります。
- **レベル。** エネルギーを実際に獲得・消費すると経験値が増え、ライフ・エネルギーの上限と攻撃力が上がります。各出撃はレベル1から始まり、エネルギーの自然回復はありません。
- **敵と残骸。** モブは通常弾を撃ち、マルティネスは小さな弾をモブの3倍撃ちます。岩を撃つ敵もいます。ガブは通常弾を撃ち、周期的にプレイヤーの貫通弾を吸収します。ガブの残骸を右クリックで回収すると、その出撃中はオンパレードが使えます。
- **ステージ。** ボスは弾幕と休止を繰り返します。ステージ1は基本の編成で、2以降にブラックホール、巨大な岩、流星群、第三勢力のギミックを順に試せます。
- **保存。** クリアすると次のステージ番号を、実行ファイルの隣の `boashot-save.txt` に自動保存します。旧形式（`BOASHOT_1`）からはステージ番号を読み込み、新形式（`BOASHOT_2`）で保存します。失敗時は同じステージを再試行できます。

## 試遊用の仮設定

キー割り当て、各数値、スキルの取得方法とギミックの出現順は試遊用です。

| 項目 | 仮設定 |
| --- | --- |
| 初期値 | ライフ100、エネルギー35 / 120 |
| 吸収 | 半径280 px、開き約74度、最長2.4秒。クールタイムは使用時間の0.9倍 |
| 通常ショット | 基本威力4、連射間隔0.28秒。最初に当たった敵にダメージ |
| チャージ | 毎秒28確保、最低8で発射。8未満で離すと全量返却 |
| グレネード | 1発につき16消費、爆発半径110 px |
| バリア | 毎秒14消費 |
| レベル | 初回45 XP、以降は必要量が20ずつ増加。最大Lv 10。1レベルにつきエネルギー上限+20、最大ライフ+8、攻撃力は基本値の8%分上昇 |
| オンパレード | 20消費で6秒間、吸収半径420 px・開き約109度、クールタイム半減 |
| ステージ | 約47秒の共通道中と共通ボス。ステージが進むと敵HPが上昇し、ギミックは5ステージで一巡 |

描画はDxLibの図形による仮素材です。BGM・効果音・ゲームパッドには未対応です。


## ビルド

Visual Studio 2022の「C++によるデスクトップ開発」とWindows SDKが必要です。

```powershell
# ゲームのReleaseビルド
powershell -ExecutionPolicy Bypass -File scripts/build.ps1 -Configuration Release

# 描画ライブラリに依存しないゲームロジックのテスト
powershell -ExecutionPolicy Bypass -File scripts/build.ps1 -Tests
```

または `boashot.sln` を Visual Studio で開き、Debug | x64 を選んで F5 を押します。Visual Studio と PowerShell のどちらでも、初回のゲームビルド時に公式の DxLib 3.25a を自動取得します。初回の取得にはインターネット接続が必要です。以降は取得済みの SDK を再利用します。既存 SDK を利用する場合は `DxLibDir` をヘッダー・LIB のあるフォルダに指定できます。

SDKはGit管理対象外の `dependencies/DxLib` に配置します。セットアップ時に公式ヘッダーのCP932をローカルコピー内でUTF-8に変換し、プロジェクトの `/utf-8` 設定と合わせています。

- [DxLib公式ダウンロード](https://dxlib.xsrv.jp/dxdload.html)
- [公式Visual Studio 2022設定手順](https://dxlib.xsrv.jp/use/dxuse_vscom2022.html)
- 使用SDK：3.25a（公式アーカイブSHA256：`DB9E6138C1665C9D9081DD04019219F332A1185448162FDBBC6F8182B9E4A847`）

遊ぶだけの PC では DxLib SDK の準備は不要です。配布時は、Release ビルドで生成した `boashot.exe` と、同じフォルダにコピーされる著作権表示 `dxlicense.html` を一緒に渡してください。

## 検証

`tests/GameTests.cpp` は即時吸収と時間制限、エネルギーと経験値の収支、アクション、スキル、ボスとステージ進行を確認します。

```powershell
# DxLibの画面を描画し、smoke-*.pngを出力して終了（セーブしません）
./x64/Release/boashot.exe --smoke
```

起動したフォルダに、タイトル、吸収、クールタイム、チャージ、グレネード、スキル、ボス、クリアの画面を出力します。

## コードの構成

- `src/Main.cpp` — Windows の起動入口
- `src/Application.h` / `src/Application.cpp` — DxLib の起動・終了、ゲームループ、入力、画面遷移
- `src/Game.h` / `src/Game.cpp` — 出撃中の状態、戦闘ルール、ステージ進行
- `src/Renderer.h` / `src/Renderer.cpp` — タイトル、戦闘画面、HUD の描画
- `src/ProfileStore.h` / `src/ProfileStore.cpp` — ステージ進行データの読み書き
- `src/SmokeTest.cpp` — `--smoke` の自動入力と画面出力
