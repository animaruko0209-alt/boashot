# ボアショット / BOASHOT

敵の弾幕を前方の扇形で吸い込み、そのエネルギーを通常弾・貫通チャージショットに変える、DxLib製の横スクロールシューティング試作版です。Windows / Visual Studio 2022 / C++17向け。

## すぐに遊ぶ

ビルド済みの `x64/Release/boashot.exe` を起動し、Enterで出撃します。初回は基本機体で始まり、約47秒の道中の後にボスが登場します。ボスを倒すと100 XPを獲得し、進化画面へ進めます。

| 操作 | キー |
| --- | --- |
| 移動 | WASD / 矢印 |
| 吸収 | マウス右ボタン（初期設定：押している間） |
| 通常射撃 | マウス左ボタンを押している間、連射 |
| チャージ | Spaceを押し続ける（この間は発射しません） |
| チャージショット | 8以上を確保してからSpaceを離す |
| 防御型のバリア | 左右いずれかのShiftを押し続ける |
| 操作設定 | F1 → Xで長押し式 / 切り替え式を変更 |
| 一時停止・再開 | P / Esc（再開はEnterでも可） |
| タイトルへ戻る | 一時停止中にQ |

吸収・通常射撃・チャージは切り替えて使います。最後に開始した操作が優先され、前の操作を再開するには押し直します。吸収や通常射撃へ切り替えた場合、チャージ用に確保したエネルギーは全量戻ります。設定画面と非アクティブ時はゲームが停止します。

## 実装した仕組み

- 前方扇形による吸収。弾を引き寄せながらエネルギーを抜き取り、到達前から射撃に使えます。
- 同時に吸う弾が多いほど引き寄せが遅くなります。各弾からエネルギーを抜く速さは変わりません。時間制限・クールタイムはありません。
- 弾の残エネルギーに比例して、その弾の接触ダメージが減少します。吸収中に扇形内から到達した弾は安全に完全吸収します。
- 途中で解除した弾は元の速度・方向で飛び、減った威力を維持します。エネルギーが空になった弾は無害な輪郭になり、回収するか画面外に出るまで残ります。
- 左クリックを押している間は通常弾を約0.12秒間隔で連射します。Spaceはチャージ専用で、押している間に弾は出ません。Spaceを離した時点で確保量が8以上なら貫通チャージ弾を発射し、8未満なら確保分を返却します。貫通弾の威力は確保量に応じて増加し、一発ごとの固定上限はなく、所持量が上限です。
- 通常敵は少量の弾を発射。強敵は大量の弾を複数回に分けて発射（仮採用案）。短い予告の後に攻撃し、前方に残って反撃の時間を作ります。
- 岩を撃つ専用敵。岩は吸収不可で、防御型以外は回避します。通常の敵を倒しても既存の弾は消えません。撃破による補給アイテムや専用補給敵はありません。
- ボスは弾幕を撃つ時間と攻撃を休む時間を繰り返します。休止中も無敵にはなりません。撃破時は戦闘終了として残弾を消します。
- 戦闘中のレベルアップはありません。クリア後のみ経験値を獲得。射撃用エネルギーとHPは次の出撃時に初期化します。
- 攻撃・吸収・防御の3進化系統。選択後の系統変更は不可で、確定前に確認画面を表示します。同じ系統でランク3まで強化できます。
- 設定・進化・経験値・次のステージ番号を、実行ファイルの隣の `boashot-save.txt` に自動保存します。再起動後も進化画面から続けられます。失敗時はクリア済みの成長を失いません。

## 試遊用に仮置きした内容

以下は会話で最終決定していない調整値です。試遊後に変更する前提です。

| 項目 | 仮設定 |
| --- | --- |
| ステージ構成 | 約47秒の共通道中＋共通ボス。次ステージは同構成で敵HP上昇 |
| HP | 基本100、防御型130。被弾後0.7秒無敵 |
| 初期エネルギー | 全出撃共通35。自然回復なし |
| エネルギー上限 | 120＋進化ランク×20。満タンでは途中のエネルギー抜き取りを停止 |
| 吸収範囲 | 半径280、開き約75度。吸収型は半径360、約94度 |
| 引き寄せ | 同時対象数で減速、最低速度あり。吸収型は1.35倍 |
| 通常射撃 | 約0.12秒間隔。1発1.2消費（攻撃型は1.6） |
| チャージ | Spaceで毎秒28確保、最低8でチャージ弾。8未満で離すと全量返却し発射しない |
| 攻撃型 | 通常弾・チャージの威力増加、通常弾の消費増加 |
| 吸収型 | 範囲・回収速度増加、射撃威力低下 |
| 防御型 | HP増加。バリアは毎秒14消費し、全方向の弾・岩を防ぐ。展開中は吸収・射撃不可 |
| 経験値・進化 | クリア100 XP、初回分岐100 XP、ランク2は200 XP、ランク3は300 XP |

描画はDxLibの図形を使った仮素材です。専用画像、BGM・効果音、複数の固有ステージ、スキル、オンパレード、地形ギミック、ゲームパッド対応は未実装です。

## ビルド

Visual Studio 2022の「C++によるデスクトップ開発」とWindows SDKが必要です。

```powershell
# 初回のみ：公式DxLib SDKをダウンロード・展開
powershell -ExecutionPolicy Bypass -File scripts/setup-dxlib.ps1

# ゲームのReleaseビルド
powershell -ExecutionPolicy Bypass -File scripts/build.ps1 -Configuration Release

# 描画ライブラリに依存しないゲームロジックのテスト
powershell -ExecutionPolicy Bypass -File scripts/build.ps1 -Tests
```

または `boashot.sln` を開き、x64 / Releaseを選択してビルドします。Win32構成もSDKのライブラリを参照しますが、検証対象はx64です。既存SDKを利用する場合は `DxLibDir` をヘッダー・LIBのあるフォルダに指定できます。

SDKはGit管理対象外の `dependencies/DxLib` に配置します。セットアップ時に公式ヘッダーのCP932をローカルコピー内でUTF-8に変換し、プロジェクトの `/utf-8` 設定と合わせています。

- [DxLib公式ダウンロード](https://dxlib.xsrv.jp/dxdload.html)
- [公式Visual Studio 2022設定手順](https://dxlib.xsrv.jp/use/dxuse_vscom2022.html)
- 使用SDK：3.25a（公式アーカイブSHA256：`DB9E6138C1665C9D9081DD04019219F332A1185448162FDBBC6F8182B9E4A847`）

ビルド時にSDK同梱の `dxlicense.html` を実行ファイルの隣にコピーします。実行ファイルを渡す場合は、この著作権表示も同梱してください。

## 検証

`tests/GameTests.cpp` で吸収の範囲・途中解除・ダメージ軽減・空の弾・同時吸収の減速・エネルギー保存・操作優先・チャージ返却・貫通・バリアの系統制限・ボスの隙・ステージ進行・経験値・分岐固定を確認します。

```powershell
# DxLibの実画面を自動描画し、smoke-*.pngを出力して終了（セーブしません）
./x64/Release/boashot.exe --smoke
```

描画確認用の自動操作・シーン固定を含みます。手動プレイでの難易度・操作感の評価は別途必要です。

主なファイル：`src/Game.h` / `src/Game.cpp` がゲームロジック、`src/Main.cpp` がDxLib描画・キー入力・画面遷移・保存です。
